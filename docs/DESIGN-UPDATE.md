# ScholarRise frontend redesign

The homepage layout was informed by https://scholarships2u.com/: prominent scholarship discovery, catalog statistics, opportunity cards, benefits and a student journey section. ScholarRise keeps its own branding, content, black/gold palette, logo, data, React workflows and backend service layer. No third-party logo, student testimonials or numerical impact claims were copied.

Changed implementation: `src/main.jsx`, new `src/redesign.css`, and homepage interaction/responsive checks in `tests/browser/platform.spec.js`. Existing components and dashboard functionality are retained; the new stylesheet also aligns workspace/forms/dialogs with the refreshed type scale and palette. No backend or AWS configuration was changed.

The hero image is saved in `public/scholarrise-campus.png`. It is an original AI-generated illustrative campus photograph, created with the built-in image generation tool. The existing ScholarRise logo was not edited or replaced. Hero prompt:

> Create a polished editorial university campus photograph for a scholarship discovery website hero. Modern cream stone academic architecture and lush tropical foliage softly out of focus, rich warm late-afternoon golden sunlight, natural dark green and charcoal shadows, cream clothing and subtle warm golden details. Premium authentic education campaign photography, realistic natural skin, refined film-like lighting, no oversaturated colors. Landscape 3:2 composition with both students clearly visible toward the center, generous background, no text, no logos, no watermark, no typography or graphic overlays. This is an original hero image, not a recreation of a particular website.

Homepage statistics are derived from the active published catalog, including clearly labeled demo records. They are collection counts, not claims of awarded funds, student outcomes or university partnerships. Destination shortcuts update the existing country filter. The hero registration button opens the existing account dialog; no new authentication mechanism was introduced.

The readability update increases body copy, navigation, card headings, labels and icon sizes across the site. Form controls use 16px text with larger touch areas; phones use a single-column filter layout so longer selections remain readable. Tablet navigation moves into the menu, cards/dialogs use softer corners, and workspace spacing accommodates the larger type. The redesign stylesheet is loaded after component styles so the size changes also apply to account dialogs and controls. The logo, data, API behavior and backend are unchanged.
